## 판정

**되돌리기 루프는 무의미해지지 않았다.** `temperature: 0.4` 가 사라졌는데도 1회차가 초안과
실제로 다른 글을 내어 결함(약한 오프닝)을 없앴고, 점수가 1019 → 16 으로 떨어져 채택됐다.
같은 문장을 되풀이했다면 점수가 안 움직였을 것이다.

**단, 회차 간 다양성은 못 쟀다.** 반복을 1회로 줄였고, 되돌리기도 1회차에서 결함이 사라져
2·3회차가 아예 안 돌았다. "같은 자료로 여러 번 돌렸을 때 서로 다른 대본이 나오는가" 는
열려 있다 — 재려면 `tailor 3 30` 이 필요하다.

**gpt-4o 시절과의 비교는 없다.** 같은 자료·같은 지표로 잰 기록이 저장소에 없다.
**이 측정을 기준선으로 남긴다** — 없는 비교를 지어내지 않는다.
