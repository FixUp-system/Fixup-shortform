# reel — 컷마다 참조를 들고 굽는 흐름 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 시나리오 → 컷 분할 → 컷별 이미지 → **영상 프롬프트(fable5)** → **컷마다 r2v** 로 굽는 새 흐름 `reel` 을 만든다.

**Architecture:** 새 흐름이지만 **장치는 전부 빌려 쓴다.** `lib/reel/*` 는 얇은 배선이고, 컷 분할·이미지·참조 적재·합성·자막·크레딧·원장은 기존 모듈을 그대로 부른다. 기존 모듈에 손대는 자리는 셋뿐이고 전부 **선택 인자 하나 · 안 넘기면 예전과 글자 그대로**(회귀 0)다.

**Tech Stack:** Next.js(App Router, 순수 JS) · vitest · Anthropic SDK(`claude-fable-5`) · fal(`bytedance/seedance-2.0/reference-to-video`) · Supabase · ffmpeg

**Spec:** `docs/superpowers/specs/2026-08-21-reel-cut-r2v-design.md`

## Global Constraints

- **`main` 에 직접 쓰지 않는다.** 이 작업의 브랜치는 `feat/reel-cut-r2v` 다. 푸시·PR·배포는 사용자가 요청할 때만 한다.
- **유료 생성(fal)은 실행 전 반드시 사용자 승인.** 무료로 볼 수 있는 것(테스트·`SHOTFORM_FAKE`)을 먼저 다 한다. Task 12·13 만 값이 나가고, 그 둘은 승인 게이트다.
- **회귀 0 이 계약이다.** `lib/ad/llm.js` · `lib/i2v.js` · `lib/cuts.js` 에 더하는 인자는 **안 넘기면 옛 결과가 글자 그대로** 같아야 한다. 각인(`of`)이 그 위에 서 있어서, 한 글자만 달라도 이미 값을 치른 그림·클립이 낡는다.
- **판정은 테스트가 한다.** 린터도 타입체커도 없다. `npx vitest run` 이 그린인지가 유일한 관문이다.
- **화면 파일을 손댔으면 한 번 굽는다.** 화면 계약을 소스 문자열로 재기 때문에 문법이 깨진 파일을 못 잡는다. dev 서버를 **끄고** `npx next build && rm -rf .next`.
- **`SHOTFORM_DIST_DIR` 는 안 먹는다.** 굽기는 `.next` 를 덮어 dev 서버를 죽인다.
- **값이 사는 곳은 한 곳이다.** 엔드포인트 문자열은 `lib/clip-limits.js`, 가격은 `lib/pricing.js`, 단계 표는 `lib/reel/steps.js`. 라우트·화면에 숫자나 모델 문자열을 흘리지 않는다.
- **화면(`"use client"`)이 import 하는 모듈은 `fs` 를 끌면 안 된다.** `lib/reel/steps.js` · `lib/reel/doc.js` 는 순수 데이터·순수 함수여야 한다(import 문을 두지 마라).
- **프롬프트 예시는 테스트 자료와 소재도 동사도 겹치지 않게** 고른다.

```js
export function buildClipPrompt(cut, project, opts = {}) {
  // 이미지와 같은 규칙이다 — 본문만 갈리고 꼬리는 코드가 붙인다. 판정은 promptBodyOf
  // 한 자리다(판형을 안 붙이는 이유도 거기 적혀 있다).
  //
  // ★★ 2026-08-21 — opts 가 생겼다. reel 흐름은 본문을 **LLM 이 쓰고**, 첨부가 첫 프레임이
  //   아니라 참조이며(r2v), 컷 순번을 모델에게 알린다. 꼬리를 저쪽에 새로 지으면 대사·
  //   립싱크·금지문이 두 벌이 되고, 한쪽이 낡는 날 **들리는 말과 ffmpeg 자막이 갈린다.**
  // ★ opts 를 안 넘긴 호출은 한 글자도 안 달라진다 — 각인이 그 위에 서 있다.
  const body = typeof opts.body === "string" && opts.body.trim()
    ? opts.body.trim()
    : promptBodyOf("clip", cut, project);

  // 컷 순번 — **둘 다 있을 때만** 붙인다. 하나만 있으면 "몇 개 중 몇 번째"가 성립하지 않고,
  // 모델에게 반쪽 사실을 주는 것은 안 주느니만 못하다.
  const scene =
    Number.isFinite(opts.sceneNo) && Number.isFinite(opts.sceneCount)
      ? ` This is scene ${opts.sceneNo} of ${opts.sceneCount}.`
      : "";

  // 첨부 설명 — **엔드포인트를 따라간다.** i2v 는 그 그림이 실제로 첫 프레임이고,
  // r2v 는 참조다. 사실이 다르므로 문장도 다르다.
  const attach =
    opts.attach === "refs"
      ? " The attached images show what this scene, the person and the product look like."
      : " The attached image is the first frame — continue naturally from it.";

  const spoken = speechFor(cut, project);
  const context = clipContextClause(cut, project);
  const note = promptNoteClause(project, "clip_note");

  if (spoken) {
    const { line } = spoken;
    const voice = spoken.voice ? ` Voice: ${spoken.voice}.` : "";
    const langLine = langLineOf(speechLangOf(project));
    if (spoken.narration) {
      return `${body} A narrator speaks in voiceover, off-screen — no one in frame speaks or moves their lips.${voice} Says exactly, in ${langLine}: "${line}".${context}${note}${scene}${attach} Keep the subject and style unchanged. No text or letters.`;
    }
    const who = spoken.who || "인물";
    return `${body} ${who} speaks to the camera with natural lip sync.${voice} Says exactly, in ${langLine}: "${line}".${context}${note}${scene}${attach} Keep the subject and style unchanged. No text or letters.`;
  }

  return `${body}${context}${note}${scene}${attach} Keep the subject and style unchanged. No text or letters. No talking faces or lip sync.`;
}
```

> ⚠️ **옛 문자열과 대조하라.** 옛 코드는 `${note} The attached image is the first frame` 이었다. 위에서는 `${note}${scene}${attach}` 이고 `attach` 가 **앞에 공백을 하나 갖는다**. `scene` 이 빈 문자열이면 `${note} The attached image is …` 로 옛것과 **바이트 단위로 같다.** 이것이 회귀 0 단정이 재는 것이다.

```js
// reel 문서의 모양과 잠금.
//
// ★ **순수 함수다 — import 문을 두지 마라.** 화면("use client")도 이 파일을 읽는다.
//   사슬 끝에 fs 가 닿으면 빌드가 깨진다(이 저장소가 세 번 겪은 사고다).
// ★ 판정을 여기 하나에 둔다 — 라우트와 화면이 **같은 값**을 봐야 화면이 열어 준 버튼을
//   서버가 400 으로 막는 어긋남이 안 생긴다.

export function emptyReel() {
  return { status: "draft", video: null, error: null };
}

export function reelOf(project) {
  return project?.reel || emptyReel();
}

export function putReel(project, patch) {
  return { ...project, reel: { ...reelOf(project), ...patch } };
}

// 시나리오를 다시 쓸 수 있는가 — 못 막을 이유가 없으면 null 이다.
//
// ★ film 의 scenarioLock 과 같은 결이다. 다른 점은 방식이 하나뿐이라 films 를 안 돈다.
export function scenarioLock(project) {
  const reel = reelOf(project);

  // ① 이미 구운 편이 있다.
  if (reel?.video?.url) {
    return { reason: "baked", message: "이미 만든 영상이 있어요 — 시나리오를 바꾸려면 새로 시작해 주세요" };
  }

  // ② 굽는 **창** 동안도 같다. 접수는 됐는데 아직 수거 전인 구간은 video 가 비어 있어
  //    ①을 그냥 지난다 — 그 사이 고치면 굽고 있는 편만 옛 판이 되고, 값은 이미 나갔다.
  if (reel?.status === "rendering") {
    return { reason: "rendering", message: "지금 영상을 만드는 중이에요 — 끝난 뒤에는 새로 시작해 주세요" };
  }

  return null;
}

// 굽기 버튼을 열어도 되는가 — 컷마다 프롬프트가 있어야 한다.
//
// ★ 빈 배열은 **아니다.** 컷이 없는데 열면 0개를 굽고 "완성"이 된다.
export function isPromptsReady(cuts) {
  const list = Array.isArray(cuts) ? cuts : [];
  if (!list.length) return false;
  return list.every((c) => typeof c?.clip_prompt === "string" && c.clip_prompt.trim().length > 0);
}
```

```js
//
// ★★ 저장이 각인의 근거다. LLM 은 부를 때마다 다른 문장을 내므로, 굽을 때 다시 부르면

  const updateProject = deps.updateProject || updateProjectImpl;
  const writeBody = deps.writeBody || writeClipPromptBody;

  const project = await getProject(projectId, ownerId);
  if (!project) throw new Error("프로젝트를 찾을 수 없어요");
  const cuts = Array.isArray(project.cuts) ? project.cuts : [];
  if (!cuts.length) throw new Error("컷을 먼저 만들어 주세요");

  // ★ 순서대로 돈다(Promise.all 이 아니다) — 앞 컷의 shows 를 뒤 컷이 받는다.
  //   컷 수가 서넛이고 호출이 짧아 직렬로 잃는 시간이 작다.
  const next = [];
  for (const [i, cut] of cuts.entries()) {
    const has = typeof cut?.clip_prompt === "string" && cut.clip_prompt.trim();
    const wanted = only ? only.has(i) : !has;
    if (!wanted) { next.push(cut); continue; }

    const body = await writeBody(cut, project, {
      sceneNo: i + 1,
      sceneCount: cuts.length,

      prevShows: i > 0 ? (cuts[i - 1]?.shows || "") : "",
      projectId,
    });
    next.push({ ...cut, clip_prompt: body });
  }

  await updateProject(projectId, ownerId, (p) => ({ ...p, cuts: next }));
```

```js
      throw e;
    }
  }

  await updateProject(id, user.id, (p) => putReel(p, { status: "rendering", error: null }));
  // ★ **약속(promise)을 넘긴다 — 콜백이 아니다.** 콜백으로 넘기면 파이프라인이 요청 범위
  //   밖에서 시작하고, 비용 주체는 AsyncLocalStorage 에서 읽으므로 costActor() 가 던진다.
  runInBackground(
    runReelClips(id, user.id).catch(async (e) => {
      await updateProject(id, user.id, (p) =>
        putReel(p, { status: "error", error: e?.message || "영상을 못 만들었어요" })).catch(() => {});
    })
  );
  return Response.json({ ok: true });
});
```

나머지 다섯(`route.js`·`scenario`·`images`·`render`·`status`)도 같은 골격으로 만든다. `scenario` 는 `scenarioLock(project)` 를 불러 `lock` 이면 `{ error: lock.message }` 로 400 을 준다. `status` 는 `GET` 이고 `{ status, error, cuts: [{ idx, image, clip_prompt, video }] }` 를 준다. `render` 도 오래 걸리므로 `maxDuration` + `runInBackground` 를 함께 쓴다.

```js
"use client";
import { useState } from "react";
import { isPromptsReady } from "../../../../lib/reel/doc";

// 4 영상 프롬프트 — **굽기 전이다.** 여기서 고치는 것은 값이 들지 않는다.
export default function ReelPromptsPage() {
  // 프로젝트는 레이아웃이 읽어 컨텍스트에 담아 둔 것을 쓴다 — 화면마다 자기 fetch 를
  // 두면 같은 문서를 여섯 번 읽고, 한 화면이 갱신한 값을 옆 화면이 모른다.
  const { project, id, reload } = useReelProject();
  const cuts = project?.cuts || [];
  const [saving, setSaving] = useState(false);

  async function save(idx, body) {
    setSaving(true);
    await fetch(`/api/reel/${id}/prompts`, {
      method: "PATCH",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ idx, body }),
    });
    await reload();
    setSaving(false);
  }

  async function rewrite(idx) {
    setSaving(true);
    await fetch(`/api/reel/${id}/prompts`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ only: [idx] }),
    });
    await reload();
    setSaving(false);
  }

  return (
    <div>
      <p>여기서 고치는 것은 값이 들지 않아요 — 영상을 만들기 전이니까요.</p>
      {cuts.map((c, i) => (
        <section key={i}>
          <h3>컷 {i + 1}</h3>
          <textarea defaultValue={c.clip_prompt || ""} onBlur={(e) => save(i, e.target.value)} />
          <button type="button" onClick={() => rewrite(i)} disabled={saving}>다시 쓰기</button>
        </section>
      ))}
      <a href={`/reel/${id}/video`} aria-disabled={!isPromptsReady(cuts)}>영상 만들기</a>
    </div>
  );
}
```
