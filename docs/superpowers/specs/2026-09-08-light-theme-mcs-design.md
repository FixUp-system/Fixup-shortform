## 0. 왜 — 형제 제품이 남처럼 보이면 안 된다

MCS(`54.180.68.212`)와 shotform 은 같은 회사가 파는 형제 제품이다. 그런데 지금 둘은
**딴 회사 물건처럼 보인다** — MCS 는 따뜻한 미색 종이에 로즈, shotform 은 검정에 형광 핑크다.

값은 짐작하지 않았다. 2026-09-08 에 MCS 의 랜딩 · `/sns` · `/library` · `/settings` 를 실제로 열어
`getComputedStyle` 로 읽었다. 그 과정에서 **가장 중요한 사실 하나**가 나왔다.

### 0-1. MCS 는 **두 층**이다

| | 마케팅 층 (랜딩 `/`) | 앱 층 (`/sns`·`/library`·`/settings`) |
|---|---|---|
| 제목 | 68px · 굵기 **900** · 자간 −3.06px | **30px · 굵기 700 · 자간 보통** |
| 라벨 | 11px 로즈 · 자간 +1.32px | 12px **회색** · 700 |
| 바탕 | 밝음/어두움 **띠 교차** | 종이색 한 벌 (`#F5F4ED`) |
| 뼈대 | 컨테이너 1600px · 섹션 상하 81px | **사이드바 236px**(`#FAF9F5`, 선 `#E8E6DC`) · 본문 여백 16/28 |

★ **거대한 900 글자는 랜딩에만 있다.** 작업 화면은 조용하다. 그러므로 "앱 전체를 MCS 처럼"은
타이포 계약을 갈아엎는 일이 **아니라**, 같은 종이·같은 로즈·같은 도입부 리듬을 쓰는 일이다.

### 0-2. 두 층에 공통으로 흐르는 것 = 브랜드가 될 것

- 종이색 `#F5F4ED` · 잉크 `#141413` · 선 `#E8E6DC` · 카드는 흰 면
- **로즈 한 색을 세 농도로** — 라벨 `#B0446A` / 채운 버튼 `#C96A8A` / 칩 바탕 10% 투명
- **Pretendard 한 벌** (라틴·숫자까지 같은 서체)
- **화면 도입부 공식**: `작은 라벨 → 제목 → 한 줄 설명` — 랜딩이든 `/library` 든 예외가 없다
- **면 분할로 나눈다** — 그림자 0, 아주 옅은 선과 라운드 10~12px 만

## 1. 확정 사항 (사장님)

1. **어두운 벌을 버린다.** 밝은 벌 한 벌로 간다 — 테마 토글도 지운다
2. **MCS 실측값을 글자 그대로** 쓴다 (shotform 쪽으로 옮기지 않는다)
3. **home 은 결과물로 연다** (지금은 "만드는 방식 고르기"로 연다)
4. **어두운 띠는 결과물 구간에만** 둔다 — 영상은 어두운 바탕에서 잘 보인다

## 2. 토큰 — 한 곳을 바꾸면 서른네 화면이 따라온다

이 저장소는 *"색은 반드시 토큰으로 참조한다 · `:root` 밖 hex 금지"* 를 판으로 강제해 왔다
(`tests/design-system.test.js`). **그 규율이 지금 이자를 준다** — 화면 파일을 거의 열지 않고 바뀐다.

| 토큰 | 지금(어두운 벌) | 새 값 | 쓰는 곳 |
|---|---|---|---|
| `--bg` | `#1A1A1A` | **`#F5F4ED`** | 모든 화면의 바탕 |
| `--surface` | `#232323` | **`#FFFFFF`** | 카드 · 패널 |
| `--surface2` | `#2E2E2E` | **`#FAF9F5`** | 사이드바 · 안쪽 칸 |
| `--deep` | `#101010` | **`#EFEDE4`** | **가라앉은 칸**(§2-4) — 띠가 아니다 |
| `--pick` | `#FF5A52` | **`#C2402C`** | "권장" 표시 (흰 바탕 대비 4.6:1) |
| `--good` / `--warn` | `#57B383` / `#E5B93C` | **`#0E7C57` / `#9A6400`** | 됐다 / 조심 |
| `--sel` | `rgba(255,90,82,.32)` | **`rgba(176,68,106,.22)`** | 드래그로 고른 글자 |
| `--stage-dark` | `#101010` | **그대로** | 영상 무대 — 테마와 무관하게 어둡다 |
| `--line` | `#3A3A3A` | **`#E8E6DC`** | 면을 나누는 유일한 선 |
| `--ink` | `#F5F5F5` | **`#141413`** | 본문 글자 |
| `--ink-soft` | `#A0A0A0` | **`#5E5D59`** | 설명 · 보조 |
| `--accent` | `#FF58AE` | **`#B0446A`** | 라벨 · 진행 표시 |
| `--accent-soft` | `rgba(255,88,174,.10)` | **`rgba(176,68,106,.10)`** | 칩 바탕 |
| `--btn` / `--btn-ink` | `#F5F5F5` / `#1A1A1A` | **`#B0446A` / `#FFFFFF`** | 돈이 나가는 주버튼 |

**새로 만드는 토큰 셋**:

| 토큰 | 값 | 왜 |
|---|---|---|
| `--band` | `#1C1B19` | 결과물 **어두운 띠**의 바탕 |
| `--band-ink` | `#ECEAE2` | 띠 **안**의 글자 |
| `--band-soft` | `#9A968C` | 띠 안의 보조 글자 |
| `--accent-fill` | `#C96A8A` | 로즈의 밝은 쪽. **띠 안에서만** 쓴다(§2-5) |

### 2-4. ⚠️ `--deep` 을 띠로 쓰면 안 된다

`--deep` 은 **가라앉은 칸**(입력 웰·안쪽 패널)이고 `var(--deep)` 을 쓰는 자리가 **16곳**이다.
그중 `.side-step.on i` 는 그 값을 **글자색**으로 쓴다 — 어둡게 두면 액센트 칩 위 검정이 된다.
그래서 띠는 `--deep` 이 아니라 **새 토큰 `--band`** 로 만든다.

### 2-5. 대비 — 계산해서 정한 값이다

| 조합 | 대비 | 판정 |
|---|---|---|
| `--accent #B0446A` 글자 / `--bg #F5F4ED` | **4.94:1** | ✅ 본문 크기 통과 |
| 흰 글자 / `--btn #B0446A` | **5.45:1** | ✅ 주버튼은 이 조합이다 |
| 흰 글자 / `--accent-fill #C96A8A` | **3.54:1** | 🔴 밝은 바탕의 작은 글자에 쓰지 마라 |
| `--accent-fill` 글자 / `--band #1C1B19` | **4.88:1** | ✅ 띠 안 라벨은 이 조합이다 |

### 2-1. 뒤집히는 규칙 하나

주버튼은 어두운 벌에서 **"바탕의 반대색"**(흰 버튼)이었다. 밝은 화면에서 그 규칙을 그대로 따르면
검은 버튼이 되는데, 그러면 크레딧 자리(로즈)와 주버튼이 **다른 가족**으로 읽힌다.
밝은 벌에서는 **액센트를 채운다**(MCS `/settings` 의 주버튼이 그렇다).
→ `design-system.test.js` 의 "`.cta` 는 `--btn` 바탕에 `--btn-ink` 글씨" 판은 **그대로 통과한다**(값만 바뀐다).

### 2-2. 손대지 않는 토큰

- `--on-media` (`#FFFFFF`) — 사진·영상 **위에** 얹는 글자다. 밑에 깔린 것이 우리 배경이 아니므로
  테마를 따라갈 이유가 없다(2026-08-20 에 그렇게 정해 둔 자리다)
- 치수(`--ctl-*`) · 간격(`--sp-*`) · 모서리(`--r-*`) — **테마가 아니다**

### 2-3. 지워지는 것

| 무엇 | 어디 |
|---|---|
| 밝은 팔레트 블록 | `app/globals.css` 의 `:root[data-theme="light"]` (값은 위 표로 `:root` 에 흡수) |
| 테마 토글 | `components/ThemeToggle.jsx` 파일 · `components/AppShell.jsx` 의 사용처 |
| 테마 부팅 스크립트 | `app/layout.js` 의 `<head>` 인라인 스크립트(`setAttribute('data-theme','light')`) |
| 테마 판 | `tests/theme-light.test.js` **파일 통째로** |

## 3. 글자 — 두 층으로 나눈다

### 3-1. 앱층 (기본, 화면 34개)

지금 계약: 크기 `12·14·16·18·28` · 굵기 `400·600·700`.
→ **크기 28 을 30 으로 옮기는 것 하나뿐**이다(MCS 앱층 h1 이 30px). 굵기는 그대로.

### 3-2. 전시층 (예외)

`.display` 클래스 안에서만 굵기 **800~900** · 크기 **44~68px** · 자간 **−0.045em** 을 허용한다.
쓸 수 있는 곳은 **`app/home`** 과 **로그인 전 화면**(`/login`)뿐이다.
판이 이 경계를 지킨다(§6).

### 3-3. 서체를 한 벌로

지금은 라틴·숫자 **Geist** + 한글 **Pretendard** 둘이다. MCS 는 Pretendard 하나라 **숫자 모양이 다르게 보인다**.
→ `app/layout.js` 에서 Geist 를 걷고 Pretendard 하나로. `body { font-family }` 도 함께 고친다.

> ⚠️ **자막 폰트 이름을 건드리지 마라.** `globals.css` 의 `@font-face` 는 `"Pretendard Subtitle"` 이고,
> 이 이름은 `lib/subtitles.js` 의 `cssFamily` 와 **글자 그대로** 같아야 한다. 이름을 `Pretendard` 로
> 줄이면 UI 폰트와 한 가족이 되어, 어느 쪽이 이기는지가 빌드 순서에 달리고 뒤집히면
> **전 화면이 1.5MB 자막 OTF 를 받는다**(그 파일 주석의 경고 그대로다).

## 4. 부품 — 모양을 한 벌로 맞춘다

- **도입부 공식**: 모든 화면이 `eyebrow → h1 → lede` 로 연다. `home` 은 이미 그 모양이다
- **카드**: 흰 면 + `1px var(--line)` + 라운드 12px · **그림자 없음**
- **칩**: 라운드 7px · `--accent-soft` 바탕 · 로즈 글자. 경로 표기(`/reel`·`/ads`)에 쓴다
- **버튼**: 라운드 10~12px · 굵기 700

**기존 화면 규칙은 그대로 산다**(2026-08 확정) — 돈 나가는 버튼은 그 줄에 혼자 · `이전으로`는
늘 맨 아래 왼쪽 끝 · 값·크레딧 문구는 ⑤영상에서만.

## 5. `home` 재구성

지금 `home` 은 `원클릭 vs 단계별` 을 그림으로 비교해 고르게 한다. 그 일은 **도구 격자**가 대신한다.

```
① 어두운 띠 — 최근 완성본 격자 (결과물 먼저)
② 도구 격자 — /ads 원클릭 · /create 단계별 · /reel 통짜
③ 작동 원리 4단 — 소재 → 시나리오 → 굽기 → 보관함
```

- ①의 자료는 `GET /api/projects` 다. **영상을 물지 않는다 — 표지 그림(poster)만 그린다**
  (2026-09-07 전송량 사고의 교훈이다: 목록이 영상을 물면 그것만으로 할당량이 탄다)
- 완성본이 없는 계정은 ①을 **통째로 감춘다**(빈 격자를 보이지 않는다). 그때는 ②가 첫 화면이다
- ③의 번호(01~04)는 **실제 순서**라서 붙인다. 장식이면 떼는 것이 맞다

## 8. 위험과 함정

- 🔴 **밝은 바탕에서 흰 글자**가 남는 자리 — 토큰을 안 쓰고 hex 를 박아 둔 곳이 있으면 그렇게 된다.
  판이 `:root` 밖 hex 를 막아 왔으므로 **원칙적으로 0건**이지만, 인라인 `style={{ }}`(판이 10곳까지
  허용한다)은 그 그물 밖이다 → **그 10곳을 눈으로 본다**
- ⚠️ **사진·영상 위 글자** — `--on-media` 를 안 쓰고 `--ink` 를 쓴 자리가 있으면 밝은 벌에서
  흰 배경 위 검정이 아니라 **사진 위 검정**이 된다. 2026-08-20 에 한 번 밟은 함정이다
- ⚠️ **자막 폰트 이름 충돌** (§3-3) — 전 화면이 1.5MB OTF 를 받게 되는 사고
- ⚠️ **대비** — §2-5 표가 정답이다. 요지: **주버튼은 `--btn #B0446A` + 흰 글자**(5.45:1)이고,
  `--accent-fill` 은 밝은 바탕에서 흰 글자를 얹으면 **3.54:1 로 모자란다** — 띠 안에서만 쓴다
- ⚠️ **`--deep` 오해** — 띠로 쓰면 16곳이 까매진다(§2-4). 띠는 새 토큰 `--band` 다
