# 목소리를 클립이 만든다 — Seedance 네이티브 음성

> 2026-08-12 · 대상: `lib/cast.js` · `lib/clip-limits.js` · `lib/i2v.js` · `lib/pipeline.js` ·
> ③목소리 단계. **Kling v3 경로는 이번 범위가 아니다** — 지금처럼 TTS 낭독을 쓴다.

## 무엇을 바꾸나

지금은 목소리를 우리가 만든다(ElevenLabs TTS). 앞으로 **Seedance 프로젝트에서는 클립이
직접 말한다** — 등장인물의 입모양까지 함께 온다.

사장님 입장에서는 ③목소리 단계가 사라진 것처럼 보인다. 자료를 주면 대본이 나오고,
그림이 나오고, 사람이 말하는 영상이 나온다.

### 근거는 실측이다 (사용자, 2026-08-12)

fal.ai 에서 Seedance 로 직접 만들어 확인한 것:

| 관측 | 결과 |
|---|---|
| 입모양·목소리 품질 | 그대로 쓰고 싶을 만큼 좋다 |
| **말한 내용** | **전달한 대본 그대로였다** |
| 지정한 길이 안에서 | 길이에 맞춰 자연스럽게 말했다 |
| 화면에 그려진 자막 | 쓸 만하지만 **한글이 변형된다** |

★ **아직 모르는 것 하나**: 클립을 여러 개 만들었을 때 목소리가 같은가. 단일 클립만
확인했다. 한 편은 컷을 따로 만들어 이어 붙이므로, 컷마다 목소리가 달라지면 한 편 안에서
화자가 바뀐 것처럼 들려 광고로 못 쓴다. **이것이 이 설계의 유일한 치명적 미지수다.**

## 왜 캐스팅에 얹는가

이 저장소는 **그림에서 같은 문제를 이미 그렇게 풀었다.** `lib/cast.js` 의 `look` 이
그 자리다:

> look 은 그 인물의 외형이다 … 이것이 전 컷의 그림 지시에 그대로 실려 같은 사람이
> 그려진다. 사진이 없을 때 일관성을 만드는 것은 이 한 줄뿐이다 — 실측에서 이것이 없어
> **컷마다 다른 사람이 나왔고 한 컷은 성별까지 달랐다.**

캐스팅은 영상당 **한 번** 돌고, 인물이 자기 컷 번호를 답한다. 그래서 "같은 사람에게 같은
값"이 프롬프트 약속이 아니라 코드 보장이다. 목소리도 같은 성질의 문제이므로 새 계층을
만들지 않고 이 축을 넓힌다.

## 구조

### 1. 캐스팅이 목소리를 정한다

`cast[]` 에 `voice` 를 더한다. `who` 는 인종까지 적게 넓힌다.

```json
{"who":"20대 동양인 남성 농구 선수",
 "look":"짧은 검은 머리, 마른 근육형, 검정 민소매 유니폼과 빨강 반바지",
 "voice":"중저음, 차분하고 단단한 톤",
 "cuts":[1,2,3,4,5]}
```

- `voice` 는 **음색과 톤**이다. 나이·성별은 `who` 에 이미 있으므로 되풀이하지 않는다
- `look` 과 같은 규칙을 따른다: **한 번 정하면 바꾸지 않는다**
- 사장님이 고른 목소리(`voice_label` — "차분한 여성" 등)를 캐스팅에 **힌트로 넘긴다.**
  그 선택을 버리지 않되, 최종 문구는 캐스팅이 인물에 맞게 쓴다
⚠️ **미결**: 인물이 없는 영상(사물·정보)에서는 `cast` 가 빈 배열이라 `voice` 를 적을
자리가 없다. 그때 목소리는 화면 밖 내레이션인데, 그것을 어디가 정할지 이 설계는 정하지
않았다 — Phase 0 이 인물 있는 영상을 재고 나서 정한다. **그전까지 Seedance 클립 음성은
인물이 있는 영상에만 켠다**(`cast` 가 비면 TTS 경로로 떨어진다).

★ `look` 의 "얼굴 생김새는 적지 않는다 — 지금 기술로는 지켜지지 않는다" 와 같은 한계가
목소리에도 있을 수 있다. **그것을 재는 것이 Phase 0 다.**

### 2. 음성을 누가 만드는가는 모델이 정한다

`CLIP_PROFILES` 에 플래그 한 줄을 더한다(모델별 `extra` 옆자리).

| 모델 | 음성 | 이유 |
|---|---|---|
| `bytedance/seedance-2.0` | **클립이 만든다**(인물이 있을 때) | 오디오를 켜도 **값이 같다**. 립싱크 품질 실측됨 |
| `fal-ai/kling-video/v3` | TTS 낭독(지금 그대로) | 켜면 단가 $0.084 → **$0.126**(1.5배)이고 립싱크 미검증 |
| `fal-ai/ltx-2` | TTS 낭독(지금 그대로) | 레거시 |

Seedance 의 `extra.generate_audio` 를 `false` → `true` 로 뒤집는다. 지금 그것을 끄는
이유가 주석에 "우리 낭독과 두 겹이 되고, 낭독이 컷 길이를 정하는 뼈대와 어긋난다" 인데,
**이 설계는 그 두 전제를 함께 없앤다** — 낭독을 안 만들고, 뼈대도 옮긴다.

### 3. 컷 길이의 뼈대가 낭독에서 추정으로 옮겨간다

지금은 ③목소리가 낭독을 실측해 `cut.seconds` 를 덮고, 그 값이 클립 길이·자막 타이밍·
합성 길이를 전부 정한다. Seedance 경로에는 잴 낭독이 없다.

**컷이 분할될 때 이미 계산해 둔 추정 초(글자 수 ÷ 5.5)가 최종값이 된다.** 모델이 그
길이에 맞춰 말하므로 성립한다.

바뀌는 것:
- `cutSeconds`(`lib/subtitles.js`)가 낭독이 아니라 `cut.seconds` 를 읽는다
- 합성이 클립을 **자르지 않는다.** 지금은 낭독 길이로 `trim` 하는데, 그러면 말이 잘린다
- ③목소리 단계는 **없애지 않는다.** Kling 경로가 그대로 쓴다 — Seedance 프로젝트에서만
  건너뛴다(`lib/steps.js` 의 단계 표는 그대로 두고 라우팅 가드가 판정한다)

★ **추정이 틀리면 어떻게 되는지가 새 위험이다.** 지금은 실측이 덮어 주었다. 넘치면
뒤에 무음이 남고, 모자라면 말이 급해진다. Phase 0 에서 함께 관측한다.

### 4. 자막은 그대로 우리가 태운다

Seedance 가 그리는 자막은 한글이 변형된다(실측). 이 저장소가 이미 못 박은 규칙과 같다:

> 레퍼런스는 복사가 아니라 참고다. 작은 글자는 "글자처럼 생긴 무늬"로 재생성된다.
> **정확해야 하는 것은 자막이 맡는다**(ffmpeg 가 원고를 그대로 태운다).

클립 지시에 글자를 요구하지 않는다. 자막 경로는 한 줄도 안 바꾼다.

## 값

- TTS 가 빠진다(컷당 $0.002 — 작다)
- 클립 단가는 **안 바뀐다**(Seedance 는 오디오를 켜든 끄든 같다)
- 그래서 정가표(`VIDEO_PRICE`)는 손대지 않는다
- 재생성 종류 `voice`(1크레딧)는 Seedance 프로젝트에서 **부를 수 없다** — 목소리만
  다시 만드는 것이 불가능하다(클립과 한 몸이다). 목소리가 마음에 안 들면 클립 재생성이다

## Phase 0 — 실측 (구현보다 먼저)

**컷 3개짜리 한 편을 Seedance 음성으로 만든다.** 15초 기준 80 크레딧.

재는 것:

1. **컷 간 목소리 일관성** ← 가장 중요. `voice` 한 줄을 전 컷에 똑같이 실었을 때
   목소리가 이어지는가. 이어지지 않으면 **이 설계는 성립하지 않고**, 목소리를 고정하는
   장치가 설계의 중심이 된다
2. **길이 정확도** — 추정 초 안에서 말이 끝나는가. 무음이 얼마나 남는가
3. **`voice` 문구가 먹히는가** — "중저음"을 적었을 때 실제로 그렇게 나오는가
4. **자막 요구를 안 했을 때 글자가 안 나오는가**

판정:
- 일관성이 유지됨 → 설계대로 구현
- 무너짐 → **구현하지 않는다.** 관측값을 남기고 목소리 고정 방법을 다시 설계한다
- 길이가 크게 어긋남 → 추정 계수(5.5자/초)를 실측 분포에서 다시 뽑는다

## 지켜야 할 것

- **Kling 경로를 건드리지 않는다** — TTS·낭독 실측·`trim` 이 그대로 살아 있어야 한다
- 캐스팅 실패 시 폴백(문장으로 도는 경로)을 깨지 않는다
- 자막 경로를 건드리지 않는다
- `lib/pricing.js` 의 정가표를 바꾸지 않는다
- **측정 없이 품질을 주장하지 않는다** — Phase 0 없이 구현으로 넘어가지 않는다

## 이번에 안 하는 것

- Kling 오디오(단가 1.5배 + 립싱크 미검증)
- 목소리 선택 UI 개편 — 지금 값을 힌트로 넘기기만 한다
- 사장님이 쓴 시나리오를 그대로 따르는 입구(별건이다 — 앱이 자동으로 쓰는 쪽을 택했다)
- 화면 밖 내레이션(인물 없는 영상)의 목소리 설계 — Phase 0 이후에 정한다
