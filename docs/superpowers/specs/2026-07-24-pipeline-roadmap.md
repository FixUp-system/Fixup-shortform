# 파이프라인 로드맵 (기준 문서)

날짜: 2026-07-24 / 출처: `2026-07-24-pipeline-spec-source.md` (원문, 수정 금지)
이 문서가 앞으로의 기준이다. 원문의 목표는 그대로 받되, 현재 코드 실측과 이미 내린 결정(D1~D12)에 맞춰 순서와 범위를 조정했다.

## 1. 원문에서 바꾼 것

| 원문 | 이 문서 | 이유 |

| 입력에 타깃 플랫폼·길이·스타일 선호 | 전부 없음. 자료 텍스트 + 사진만 | 07-23 실험 결론(정보량이 본질) + 07-24 결정. 길이는 TTS 실측이 확정하고, 비율은 9:16 고정 |

## 2. 현재 코드 실측 (2026-07-24, `feature/staged-workflow-m1`)

| 원문 단계 | 상태 | 실제 |
|---|---|---|
| ① 씬 분해 | 부분 | `lib/script.js` 대본 → `lib/cuts.js` 컷. `visual_description`·`camera`·`mood`·`role` 없음 |
| ② 대본 게이트 | 있음 | 문단 편집 + 수정 지시 + coverage |
| ③ TTS → 타이밍 | **없음** | `seconds`는 LLM 추정 |
| ④ 레퍼런스 | 부분 | 업로드 사진 주입 경로 동작(nano-banana `/edit`). 스타일 시트·공통 스타일 토큰 없음 |
| ⑤ 이미지 + QC | 있음 | 후보 2장 → VLM 선별 → 지적사항 반영 1회 재시도 → `needs_attention` 격리 |
| ⑥ 영상화 + QC | 없음 | `/api/video`의 Kling/Veo 어댑터 재활용 가능 |
| ⑦ 씬 단위 재생성 | 부분 | 이미지 재생성 3회. 영상화 단독 재시도·대본 연동 재생성 없음 |
| ⑧ ffmpeg 병합 | 없음 | 자막·덕킹·-14 LUFS·세이프존·인코딩 전무 |
| 잡 큐/상태머신 | 부분 | 컷 상태·실패 격리는 있으나 큐 없음. 서버 재시작 시 `generating` 영구 잔류, 재개 경로 없음 |
| 모델 어댑터 | 부분 | 영상 O / 이미지 △(fal 단일) / TTS X |
| 산출물 저장 | 부분 | `data/*.json` + 업로드 사진. **생성 이미지는 fal 원격 URL만 보관** |
| 비용 추적 | 부분 | 호출당 기록. 프로젝트·컷 귀속 없음 |

## 3. 확정 순서

```
① 자료 (텍스트 + 사진)
② 대본 생성 → [게이트 1: 대본 확정]        무료
③ 컷 분할 (씬 스키마)
④ TTS → 컷별 실측 길이 확정               ← 클립 길이의 유일한 기준
⑤ 레퍼런스 확보 → [게이트 2: 사진 없을 때만 스타일 승인]
⑥ 컷별 이미지 생성 + VLM QC
⑦ 이미지 → 영상화 + QC → [게이트 3: 최종 검수·컷 단위 재생성]
⑧ 자막 + 병합/믹싱/인코딩 (전부 코드)
```

원문의 핵심 순서 결정을 그대로 따른다: **클립 길이는 오디오가 정한다.** ④가 ⑥⑦ 앞에 있는 이유다.

현행 게이트 2(컷별 이미지 확인)는 게이트 3으로 흡수한다. 이미지만 따로 검수시키면 사장님이 같은 컷을 두 번 본다.

## 4. 우선순위

**P0 — 순서 바로잡기**
- 컷 스키마 보강: `role`(hook/body/cta), `visual_description`, `mood` 추가. 이미지 프롬프트의 원천을 문장이 아니라 `visual_description`으로
- TTS 어댑터 + 컷별 오디오·character 타임스탬프 저장, `actual_audio_duration`을 컷에 기록
- 컷 분할과 이미지 생성 분리(현재 `runCutsPipeline`이 한 덩어리) — 사이에 ④가 들어가야 한다
- **생성 이미지 로컬 보관** (fal URL 만료 대비). ⑧을 붙이는 순간 터질 부채
- **고아 `generating` 복구**: 서버 재시작 시 잔류 상태를 `needs_attention`으로 회수

**P1 — 영상까지**
- 영상 어댑터를 컷 파이프라인에 연결(이미지 → 클립, `actual_audio_duration` 기준)
- 클립 QC(첫/끝 프레임 VLM), 게이트 3 UI(컷 단위 재생성 3종: 이미지만 / 영상만 / 대본 수정 후)
- ffmpeg 병합: 컷 이어붙이기 + 내레이션 믹싱 + 자막 번인(세이프존) + -14 LUFS + 9:16 인코딩

**P2 — 품질·운영**
- 스타일 토큰 공통 suffix, 사진 없는 프로젝트용 스타일 시트 + 게이트 2
- BGM 무드 선택·덕킹
- 스토리지(S3 등)·렌더 워커·잡 큐 도입 결정 (여기서 한꺼번에)
- 비용을 프로젝트·컷에 귀속

**P3 — 정책**
- 크레딧 차감 구현(영상형 3 / 슬라이드형 1, 재생성 상한)
- 폴백 모델, 지수 백오프

## 5. 열린 결정

- **TTS 모델** — character 타임스탬프를 주는 것으로. 한국어 품질이 선정 기준
- 스토리지·렌더 워커 인프라 (ffmpeg가 Vercel 함수에서 도는지가 갈림길)
- 슬라이드형(D8) 경로를 ⑥ 생략으로 처리할지, 별도 렌더 경로로 둘지

## 6. 진행 중 작업에 미치는 영향

`feature/deferred-settings`(설정 지연): 목적·길이 제거는 이 로드맵과 일치하므로 그대로 간다. **비율 선택은 폐지** — 9:16 고정이므로 대본 게이트에 비율 칩을 두지 않는다. 예상 초 표시는 P0에서 TTS 실측으로 교체될 임시 표시다.
