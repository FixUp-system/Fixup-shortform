# 대본 생성 품질 — AI 티 제거, 담담한 정보 전달

날짜: 2026-07-24 / 브랜치: `feature/deferred-settings` 후속
관련: `lib/script.js`, `app/api/projects/[id]/script/route.js`

## 배경

지금 대본은 정보는 다 담기지만 "AI가 쓴 광고 문구" 냄새가 강하다. 실측 예(딸기라떼):

```
[여는말] 성수동에서 특별한 딸기라떼를 만나보세요.
[본문]   카페 미영의 신메뉴, 생딸기라떼는 논산 설향 딸기를 직접 갈아 만들어 신선함을 자랑합니다. 시럽을 사용하지 않아 딸기 본연의 맛을 그대로 느낄 수 있습니다.
[희소성] 이 특별한 라떼는 하루 40잔 한정으로, 오전 11시부터 판매됩니다. 4월 중순까지만 만나볼 수 있으니 서둘러 방문해보세요.
[위치]   성수역 3번 출구에서 도보로 단 2분 거리에 위치한 카페 미영에서 맛보실 수 있습니다.
[마무리] 한 잔에 6500원으로, 신선한 딸기의 맛을 경험해보세요.
```

문제(우선순위 1 = AI 티·상투어): "특별한"(2회)·"자랑합니다"·"만나보세요"·"경험해보세요" 같은 알맹이 없는 광고체, 무른 명령형 남발, 문어체 광고 카피.

## 목표

**담담하고 사실 위주의 목소리.** 광고 형용사·무른 명령형·AI 필러를 걷어내고, 구체적 사실(수치·고유명사·행동)이 스스로 말하게 한다. 홍보든 기록이든 담담하게 전달한다. 톤(register)을 바꾸는 것이지 콘텐츠 성격(홍보/기록/이야기)을 고정하는 게 아니다 — 성격은 여전히 자료가 정한다.

목표 결과(같은 자료):

```
[여는말] 카페 미영은 딸기라떼에 시럽을 쓰지 않습니다.
[본문]   매일 아침 논산 설향 딸기를 직접 갈아요. 그래서 그날 딸기에 따라 단맛이 조금씩 다릅니다.
[희소성] 오전 11시부터, 하루 40잔만 만듭니다. 4월 중순까지입니다.
[위치]   성수역 3번 출구에서 걸어서 2분. 한 잔 6,500원.
```

## 방법: 2단 생성 (A + B)

### 1단 — 초안 (프롬프트 재작성, A)

`lib/script.js`의 `SYSTEM`에 세 가지를 넣는다.

**금지 목록** — 프롬프트에 명시해 쓰지 못하게 한다:
`특별한 · 특별하게 · 만나보세요 · 만나보실 · 경험해보세요 · 경험하세요 · 자랑합니다 · 다양한 · 완벽한 · 놓치지 마세요 · 최고의 · 진정한 · 잊지 못할 · 지금 바로 · 함께하세요` 및 "~해보세요"류 무른 명령형의 남발.

**문체 규칙**:
- 평서문 위주로 사실을 단언한다("시럽은 쓰지 않습니다"). 권유("~보세요")를 남발하지 않는다.
- 형용사로 부풀리지 않는다. 구체적 사실(수치·고유명사·행동)이 스스로 말하게 한다.
- 한 문장에 한 가지. 짧게.
- 첫 문단은 광고 문구가 아니라 **가장 구체적이고 센 사실**로 연다.

**대조 예시 한 쌍** (톤 참고용 — 내용을 베끼지 말라고 명시):
- ✗ `성수동에서 특별한 딸기라떼를 만나보세요. 신선함을 자랑합니다.`
- ✓ `카페 미영은 딸기라떼에 시럽을 쓰지 않습니다. 매일 아침 논산 설향 딸기를 직접 갈아요. 하루 40잔만 만듭니다.`

기존 규칙(분량은 자료가 정함, coverage 나열, 과장·허위 금지, tag는 역할)은 유지한다. 훅 규칙은 "센 사실로 연다"로 흡수해 광고 문구를 배제한다.

### 2단 — 자기 교정 패스 (B)

초안이 나오면 **두 번째 LLM 호출**이 그 초안을 받아 다시 쓴다. `lib/script.js`에 `buildScriptEditMessages(draft)` 신설 — 입력은 **초안뿐**이다. 원문 자료를 다시 주지 않는다(초안이 일부러 뺀 내용을 교정이 되살리는 걸 막는다).

교정 패스의 일은 **좁게** 정의한다:
- 광고 티·상투어·무른 명령형을 걷어내고 담담한 평서문으로 바꾼다.
- **초안의 사실을 하나도 빠뜨리지 않는다** — 수치·고유명사·위치·특징 그대로. 새 사실을 더하지 않는다. coverage는 초안 것을 유지한다.
- 문단 수·구조와 (사용자가 초안에 요청한) 톤을 존중한다. 클리셰 제거 외에 내용을 바꾸지 않는다.
- 출력 스키마는 초안과 같다(paragraphs, coverage).

## 흐름

`app/api/projects/[id]/script/route.js`:

```
1. 초안 = validateScript(callJson(buildScriptMessages))   ← 기존, 최대 2회 시도
2. 교정 = validateScript(callJson(buildScriptEditMessages(초안)))  ← 신설, 최대 2회 시도
3. 최종 = 교정 || 초안        ← 교정이 실패(빈 JSON·스키마 불일치·오류)하면 초안으로 폴백. 작업을 잃지 않는다
4. 저장(status:"script", briefing_version 각인)  ← 기존과 동일
```

교정 호출이 네트워크·502로 던지면 잡아서 초안으로 폴백한다(대본이 아예 안 나오는 것보다 초안이라도 낫다).

## 적용 범위

- **초안 생성**과 **"수정 지시 / 전체 다시 쓰기"** 양쪽 다 교정 패스를 거친다. 항상 담담한 결과를 낸다.
- 교정 패스는 사용자가 요청한 톤을 덮지 않는다 — 클리셰 제거만.

## 하지 않는 것

- 스키마·파이프라인 변경 없음. 프롬프트 추가 + LLM 호출 1회 추가뿐.
- 루브릭 QC + 자동 재생성(원 로드맵의 "판정 2", 방법 C)은 이번 범위 밖. A+B로 부족하면 그때 검토.
- 금지어를 코드로 후처리 필터링하지 않는다 — 한국어 어미 변화로 문자열 매칭이 부서지기 쉽고, 교정 패스가 그 일을 한다.

## 비용·검증

- 대본 생성당 OpenAI 호출이 1회 → 2회. gpt-4o 짧은 호출이라 몇 센트. 이미지(fal)와 무관.
- 프롬프트 품질은 라이브로만 확인된다: A 자료(정보 충분)로 **최소 2회** 실제 생성해 before/after를 본다. 금지어가 사라졌는지, 사실이 다 유지됐는지, 첫 문단이 센 사실로 열리는지 확인한다.
- 정보 부족 자료로도 돌려 대본이 여전히 완결되는지 본다.

## 테스트

- `buildScriptMessages`: system에 금지어 지시("특별한" 등 쓰지 말라는 취지)와 대조 예시가 있다. "반드시" 강제 없음(기존 유지).
- `buildScriptEditMessages`: 초안 문장이 프롬프트에 들어가고, "사실 유지"·"상투어 제거"·"새 사실 추가 금지" 지시가 있다. 출력 스키마 지시가 초안과 같다.
- 라우트: callJson을 mock해 1번째=클리셰 초안, 2번째=담담 교정을 돌려주면 **저장된 대본은 교정본**이다. 교정이 null이면 **초안으로 폴백**한다.
- 기존 75개 그린 유지가 하한선.
